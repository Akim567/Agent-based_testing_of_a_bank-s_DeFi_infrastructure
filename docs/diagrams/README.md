# Схемы проекта

В этой директории хранятся наглядные схемы, которые объясняют устройство
испытательного стенда и процессы внутри него.

- [`stand-architecture.md`](stand-architecture.md) — из каких компонентов состоит стенд и как они связаны.
- [`operation-lifecycle.md`](operation-lifecycle.md) — как банковская криптовалютная операция проходит через стенд.
- [`agent-testing-cycle.md`](agent-testing-cycle.md) — как AI-агент исследует стенд, обнаруживает нарушение и формирует воспроизводимый тест.

Схемы записаны в формате Mermaid и отображаются прямо в GitHub. При изменении
архитектуры сначала нужно обновить `docs/architecture.md`, а затем привести в
соответствие схемы из этой директории.
