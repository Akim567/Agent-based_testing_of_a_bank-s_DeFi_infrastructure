# Документы

Здесь хранятся материалы, связанные с оформлением ВКР: текст работы, протоколы
встреч, презентации, схема будущей системы и журнал принятых решений.

Наглядные схемы стенда и экспериментальных процессов находятся в
[`diagrams/`](diagrams/README.md).

Рабочий анализ источников и данные экспериментов следует хранить в `research/`
и `data/`, а не в этой директории.
