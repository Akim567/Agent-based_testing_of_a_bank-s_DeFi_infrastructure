рендеры и промежуточные версии лучше не добавлять либо явно помечать как draft.

- `Тестирование DeFi инфраструктуры банка_КТ1.pdf` — исходная постановка темы,

- `Контрольная точка 2 — Агентное тестирование DeFi-инфраструктуры банка.pptx`
  — пилотный анализ пяти инцидентов, YAML-формат сценария и проект MVP для КТ2.
