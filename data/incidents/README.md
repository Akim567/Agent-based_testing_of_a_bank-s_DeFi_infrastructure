# Инциденты

`catalog.csv` содержит по одной строке на каждый найденный инцидент: источник,
тип, краткую причину, применимость к стенду и статус обработки.

Исходные тексты, отчёты и сохранённые материалы размещаются в `raw/`.

Первый пилотный перевод, анализ узлов и операций, а также черновая матрица
требований для пяти инцидентов находятся в
[`pilot-01-node-analysis.md`](pilot-01-node-analysis.md).
