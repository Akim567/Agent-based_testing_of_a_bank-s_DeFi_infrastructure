# Анализ инцидентов

Основной результат — последовательные карточки по [компактному шаблону](template.md).
Каждая карточка описывает один инцидент: узлы, операции и требования. Сравнений
между инцидентами и общих аналитических таблиц в этих файлах нет.

## Ранее подготовленные материалы

Первоначальная модель и пилот сохранены как история работы. Три промежуточных
файла разборов I36–I55 удалены после переноса карточек в батчи.
Сохранившиеся исторические документы используют прежние форматы,
общие каталоги и обозначения; для чтения и дальнейшей актуализации следует
использовать карточки из раздела выше. Новые изменения анализа вносить в батчи,
не вести параллельные актуальные версии в прежних файлах.

- [Первоначальная модель I01–I35](domain-model-2026-11-26.md).
- [Пилот из пяти случаев](pilot-01-node-analysis.md) — входит в те же 915,
  отдельно повторно не учитывается.
- [Индекс исходного корпуса](corpus-register-2026-11-26.md) — 915 индексных
  записей зафиксированной версии DeFiHackLabs; не каталог 915 подтверждённых
  уникальных атак и не сравнение инцидентов.
- [Старый CSV пилота](catalog.csv) — только пять пилотных случаев,
  не полный актуальный реестр.

Исходные сохранённые материалы размещаются в [raw/](raw/README.md).
