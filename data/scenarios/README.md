# Формальные сценарии

Здесь размещаются YAML- или JSON-сценарии, полученные из описаний инцидентов.
Имя сценария должно начинаться с идентификатора соответствующего инцидента.

До начала массовых экспериментов статус сценария — generated, reviewed или
reference — можно хранить внутри самого файла без дополнительных поддиректорий.
