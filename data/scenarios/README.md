# Формальные сценарии

Здесь размещаются YAML- или JSON-сценарии, полученные из описаний инцидентов.
Имя сценария должно начинаться с идентификатора соответствующего инцидента.

До начала массовых экспериментов статус сценария — draft, reviewed или
reference — можно хранить внутри самого файла без дополнительных поддиректорий.

Черновой формат сценария описан в
[`incident-scenario-format.md`](incident-scenario-format.md). Рядом находятся
универсальный YAML-шаблон и заполненный пример по инциденту OrderFactory.
