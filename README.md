# Agent-based testing of a bank's DeFi infrastructure

Репозиторий магистерской работы об агентном тестировании банковской
DeFi-инфраструктуры на упрощённом испытательном стенде.

Текущий календарный план и прогресс находятся в [`PLANS.md`](PLANS.md).

## Постановка на КТ1

```text
Агент видит состояние стенда → выбирает действие → стенд выполняет операцию
→ независимый модуль проверяет контрольные правила → результат сохраняется
```

Эксперимент сравнивает агентный подход с заранее написанными тестами и случайным
перебором операций при одинаковом числе попыток. Подробная постановка и простое
объяснение терминов находятся в
[`research/research-framework.md`](research/research-framework.md).

После КТ1 обсуждалось уточнение темы через преобразование текстовых описаний
реальных инцидентов в формальные сценарии. Связь этой идеи с постановкой КТ1
ещё нужно согласовать с научным руководителем и зафиксировать в
`docs/decisions.md`.

## Структура

- `docs/` — текст ВКР, материалы встреч, презентации и архитектурные решения.
- `research/` — рабочий обзор источников и методика исследования.
- `data/` — корпус инцидентов и их формальные сценарии.
- `src/` — будущая программная реализация.
- `output/` — готовые результаты экспериментов.

В каждой директории находится собственный `README.md` с краткими правилами её
использования.

## Ближайший результат

1. Обсудить с научным руководителем итеративный MVP по пяти инцидентам.
2. Выбрать технологический стек для эмулятора и тестового блокчейна.
3. Реализовать один вертикальный сценарий — создание операции без согласия
   клиента по мотивам OrderFactory.
4. Проверить, что базовая модель расширяется на остальные четыре пилотных
   сценария без перестройки архитектуры.

Черновой проект MVP находится в
[`docs/architecture.md`](docs/architecture.md).
