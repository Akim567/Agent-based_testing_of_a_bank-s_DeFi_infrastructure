# Agent-based testing of a bank's DeFi infrastructure

Репозиторий магистерской работы об агентном преобразовании описаний реальных
инцидентов в формальные сценарии и их воспроизведении на упрощённом
банковско-блокчейнном стенде.

## Текущая идея

```text
Текст инцидента → формальный сценарий → запуск на стенде
→ независимая проверка нарушения → регрессионный тест
```

Основной исследовательский результат — метод перехода от неструктурированного
описания инцидента к воспроизводимой проверке. Стенд служит экспериментальной
средой и не моделирует промышленный банк целиком.

## Структура

- `docs/` — текст ВКР, материалы встреч, презентации и архитектурные решения.
- `research/` — рабочий обзор источников и методика исследования.
- `data/` — корпус инцидентов и их формальные сценарии.
- `src/` — будущая программная реализация.
- `output/` — готовые результаты экспериментов.

В каждой директории находится собственный `README.md` с краткими правилами её
использования.

## Ближайший результат

1. Уточнить методику и критерии отбора инцидентов.
2. Выбрать первые 3–5 инцидентов.
3. Зафиксировать формат формального сценария.
4. Реализовать один сквозной пример на испытательном стенде.
