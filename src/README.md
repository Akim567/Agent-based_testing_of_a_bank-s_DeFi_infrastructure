# Исходный код

Здесь будет находиться реализация агента и испытательного стенда. Базовые
границы MVP, модель данных, логические команды Bank API и минимальный набор
смарт-контрактов описаны в [`docs/architecture.md`](../docs/architecture.md).

Технологический стек пока не выбран, поэтому директория намеренно не разделена
на компоненты и программный каркас ещё не создаётся.

После реализации первого сквозного сценария код можно разделить на агент,
стенд, исполнитель сценариев и независимый oracle.
